# 風險與護欄

- 風險：agent 的自主性意味成本較高、錯誤可能累積 [S1]。
- 對策：在沙箱環境大量測試，並加上適當護欄 [S1]；設停止條件（如最大迭代次數） [S1]；在檢查點或遇阻時讓人介入 [S1]。
- 人類介入的例子：ReAct 研究讓人類檢視者編輯推理軌跡，以修正因幻覺推理而失敗的行為（ALFWorld 示例，來自 Google 部落格輔助說明） [S2]。
- OpenAI：instructions 與 guardrails 是 agent 的定義要素之一，agent 應始終在明確護欄內運作 [S4]。護欄可分層，涵蓋資料隱私、聲譽風險、相關性等（二手摘要） [S4]。
- 程式驗證：coding agent 可用自動化測試驗證，但人工審查仍然關鍵 [S1]。
